# plain-text-durability — backstory

**This is a demo unit. Its purpose is to show a complete, filled-in card stack — GLANCE → CARD →
SKILL → README — so you can see the standard every knowledge unit follows. Its content is also a
genuine, evergreen reference; keep it or delete it once you've seen the shape.**

## Why this exists as the demo
It demonstrates, in one small unit:
- The four-tier card stack, each tier rewritten for its depth (not truncated).
- Provenance and status frontmatter on `SKILL.md`.
- `CARD.yml` advertisements that route by *situation*, so an agent surfaces this note when it's
  relevant rather than only on a full-text match.
- A registered ledger row in the parent section's `SKILL.md`, and a facet in `meta/by-tag.md`.
