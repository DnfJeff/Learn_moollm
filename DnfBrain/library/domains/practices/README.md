# practices — section overview

**This is the practices-section README. What lives here, how it's organized, and notable
changes are noted here.**

Repeatable ways of working — the section that holds *how* rather than *what*. Anything you'd
re-apply on the next project belongs here: methods, patterns, checklists, settled conventions.
The library's own working conventions (like the registry pattern behind
[`../../characters/`](../../characters/README.md)) file here too — the library eats its own
cooking.

## Subclasses

them. Flat-to-structured, never empty ceremony.)*

## How to use this section
- **Browsing:** this file, then `SKILL.md` for the ledger.

- **Filing:** copy `../../_templates/unit/`, fill it, register it.
