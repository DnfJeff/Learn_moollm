# arts / film / tv — finding aid

**This is the `tv` shelf. Read this to decide whether to descend — it is the map of
this level, not a copy of what's below.**

Television. The spine here is **by decade, then by genre, then the show** — so a show's path carries its era and kind before you ever open a file (e.g. `1950s/sitcom/the-danny-thomas-show/`).

## Subdivisions (staged)
- [`1950s/`](1950s/README.md) — the first television decade: live broadcast, filmed sitcoms, variety

## Placement
A decade folder is created when its first show lands (flat-to-structured); the pattern is `<decade>/<genre>/<show>/`. A show is a carded unit; heavy shows grow `characters/`, `reviews/`, `episodes/` inside.
