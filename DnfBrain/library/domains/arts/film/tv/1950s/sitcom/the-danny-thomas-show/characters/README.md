# the-danny-thomas-show / characters — finding aid

**This is the show's character shelf: one information-heavy write-up per character or figure,
each the single source of truth for that person on this show.**

The quick-nav layer lives elsewhere by design: every write-up here has a small YAML card in
[`library/characters/`](../../../../../../../../characters/README.md) (the registry), which is
how an agent finds a person **by name** without knowing which show to open. Card routes here;
truth lives here. If the same figure earns a write-up on another show, the one registry card
routes to both — dual positioning, no duplication.

## Adding a character

1. Write the full `.md` here (frontmattered — this is the cheap-rung note form; it graduates
   to a carded directory if it grows tiers of its own).
2. Add the registry card + manifest row — the `registrar` capability
   (`capabilities/registrar/`) is the procedure.
3. Add the row above.
