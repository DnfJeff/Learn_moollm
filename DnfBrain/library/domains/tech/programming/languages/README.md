# tech / programming / languages — finding aid

**This is the `languages` shelf. Read this to decide whether to descend — it is the map of
this level, not a copy of what's below.**

One shelf per language. Each holds the language's own material: idioms, gotchas, version notes, and pointers into official documentation.

## Placement
Pattern: `<language>/` (python/, rust/, javascript/) created on first unit. Official-doc pointers are units tagged `official-docs`; if language lookup becomes a daily by-name operation, promote a registry layer for it (`library/_templates/registry/`).
