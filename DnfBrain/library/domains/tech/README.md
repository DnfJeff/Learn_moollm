# tech — section overview

**This is the tech-section README. What lives here, how it's organized, and notable changes
are noted here.**

Computing knowledge for keeps: platforms, games as systems, languages, AI, the web — down to
reverse-engineered internals. Like `arts/`, the rule is **the path carries the classification**:
`pc/gaming/simulation/the-sims/the-sims-1/technical/dev/docs/` is exactly where a file-format
doc would be shelved if this were an infinite library and you were finding the book.

## How to use this section
- **Browsing:** read this file, then `SKILL.md` for the full ledger of units.
- **Routing (agent):** `CARD.yml` decides whether new work belongs here.
- **Filing:** walk the spine to the shelf, copy `../../_templates/unit/`, register it.
- **Dual-shelf subjects:** a game is a work *and* a system. Its culture lives under
  [`../arts`](../arts/README.md); its internals live here. Cross-link both ways.
