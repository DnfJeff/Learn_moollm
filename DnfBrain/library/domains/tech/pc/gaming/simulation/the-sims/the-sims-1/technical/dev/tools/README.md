# tech / ... / the-sims-1 / technical / dev / tools — finding aid

**This is the `tools` shelf. Read this to decide whether to descend — it is the map of
this level, not a copy of what's below.**

One directory per tool: what it does, how it behaves, where it came from, and its current status — including tools that are dead. A deprecated tool keeps its shelf; the knowledge of what it did outlives the binary.

## Subdivisions (staged)

## Placement
Name pattern: `<tool>` for living tools, `<tool>-depr` for deprecated ones — the path itself carries the status a browser needs before opening anything.
