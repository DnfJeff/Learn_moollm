# The Legible Workspace — Document Series

A file-native architecture for context orchestration, presented at three resolutions. The
mechanisms originate in [MOOLLM](https://github.com/SimHacker/moollm) by Don Hopkins; the evidence base is the
[study](../study/) extraction.

The series is itself shaped like its first mechanism — a resolution ladder. Same ten
mechanisms, same names, three depths. Enter wherever you live:

| Shelf | For | Start at |
|---|---|---|
| **[onramp/](onramp/)** | Anyone — no technical background | [Why Your AI Forgets Everything](onramp/WHY-YOUR-AI-FORGETS.md) |
| **[kit/](kit/)** | Builders using Claude Code / Cursor daily | [Start Here](kit/START-HERE.md) → [Scaffold](kit/SCAFFOLD.md) |
| **[spec/](spec/)** | Engineers, framework authors, skeptics | [Whitepaper](spec/WHITEPAPER.md) → [Mechanisms](spec/MECHANISMS.md) |

Every document carries a tier bar linking one shelf **deeper** and one **plainer** for the
same content.

**[shared/CANON.md](shared/CANON.md)** is the source of truth for all names, definitions,
and analogies — when any document and the canon disagree, the canon wins. The series plan
and its production history: [SERIES-PLAN.md](SERIES-PLAN.md).
