# Plain Glossary

> **Tier:** Onramp · deeper: [kit/GLOSSARY.md](../kit/GLOSSARY.md)

Every term this shelf uses, in plain language, with its everyday picture. The technical
shelf has the [full version](../kit/GLOSSARY.md) with the original system's vocabulary.

## The approach itself

**The Legible Workspace** — the whole pattern: everything an AI assistant knows, written
down as ordinary documents people can read and fix. "Legible" is the promise: no hidden
memory, no invisible reasoning, nothing you can't open.

**MOOLLM** — the original system these ideas come from, built by Don Hopkins as a playful
explorable world. This shelf is the plain-clothes retelling.

## The ten ideas

| Term | Plain meaning | The picture |
|---|---|---|
| **Resolution ladder** | Everything written at several sizes; read the shortest one that answers you | Cover → contents → chapter → appendix |
| **Declarative routing** | Each ability announces when it's useful; nothing central to maintain | Shops hang their own signs |
| **Host drivers** | One set of instructions, plus a small adapter for each AI tool it runs in | Universal travel adapter |
| **Externalized state** | The assistant's memory and current focus are documents, not vapor | The shared project binder |
| **Standing constraints** | Always-on rules, each naming the bad habit it forbids | House rules posted on the wall |
| **Boot compilation** | Curating the sheet the assistant reads automatically at session start | The chef's mise en place |
| **In-context ensemble** | Several declared points of view argue it out in one sitting | Panel discussion, not letters in the mail |
| **Directory-as-object** | One labeled folder per ability; the shelf itself is the master list | The client-folder filing system |
| **Names as addresses** | Use names the assistant already knows; invent terms only once, on paper | "Play it Motown" |
| **Tolerant interpretation** | Sloppy requests in, precise work out; small mishaps self-heal | The good waiter |

## The three habits

**Dual-mode contract** — the written pieces work whether or not any tool enforces them:
GPS turn-by-turn where supported, printed map where not. Same directions either way.

**Determinism split** — mechanical, repeatable work goes to small automatic steps; the
assistant is saved for judgment. The spreadsheet adds; the accountant decides.

**Rewrite, not truncate** — every short version is written fresh for its reader, never
chopped off the front of the long version. A trailer is not the first two minutes of the
film.

## Everyday working terms

**The binder** — the assistant's memory as documents: a current-focus page, a decisions
log, a results page. Technical shelf calls it *externalized state* or *the session zone*.

**The focus page** — the one page saying what the assistant is working on right now. Its
special power: if the assistant is focused on the wrong thing, you fix the *page*.
(Technical name: the working set.)

**The briefing sheet** — the file the assistant's tool loads automatically at every session
start. Prime real estate: rules and pointers only. (Technical names: the boot file, the
free channel.)

**The catalog** — the one-line-per-ability table of contents the assistant checks first.

**Blurb / manual** — the sizes on the ladder: the is-this-relevant paragraph, and the full
how-it-works document. (Technical names: glance, card, skill.)

**The sign** — an ability's own statement of when it should be used. (Technical name:
a trigger, or in the original system, an advertisement — the word comes from The Sims,
where a fridge literally advertises "I can feed you.")

**Named habit** — a bad behavior given a short name and a quick test so it can be caught
in three words. The posted rules are made of these.

**The panel** — several declared perspectives debating inside one sitting. Distinct from an
**independent review**, which uses a genuinely separate reviewer and costs more — panels
explore, independent reviewers verify.

**The check** — the small automatic step that verifies the team's own rule sheets and
catalog aren't quietly broken. Exists because a helpful assistant absorbs your paperwork
errors invisibly.

**Adoption staircase** — the order to take the ideas in, with a safe stopping landing at
every step: binder first, posted rules second, the library only when you're big enough to
need a catalog.
