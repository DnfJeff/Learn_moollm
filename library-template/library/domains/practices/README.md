# practices — section overview

**This is the practices-domain README. What lives here, how it's organized, and notable changes
are noted here.**

Reusable **ways of working** — methods, patterns, checklists, standards, workflows. The stuff you
want to re-apply next time instead of re-deriving. If `technical` is "how the thing works" and
`knowledge` is "what's true about the subject," `practices` is "how I do the work."

## Subclasses
- `checklists/` — repeatable sequences and runbooks
- `patterns/` — reusable solution shapes
- `standards/` — conventions you hold yourself to

## How to use this section
- **Browsing:** this file, then `SKILL.md` for the ledger.
- **Routing (agent):** `CARD.yml` decides whether new work belongs here.
- **Filing:** copy `../../_templates/unit/`, fill it, register it.
