# knowledge — section overview

**This is the knowledge-domain README. What lives here, how it's organized, and notable changes
are noted here.**

Durable understanding of **a subject or field** — concepts, theory, research notes, and mental
models — none of it tied to a single system. If `technical` is "how this *thing* works,"
`knowledge` is "what's true about this *subject*."

## Subclasses
- `concepts/` — definitions and ideas you return to
- `research/` — synthesized understanding of a field
- `models/` — mental models and frameworks

## How to use this section
- **Browsing:** this file, then `SKILL.md` for the ledger.
- **Routing (agent):** `CARD.yml` decides whether new work belongs here.
- **Filing:** copy `../../_templates/unit/`, fill it, register it.
